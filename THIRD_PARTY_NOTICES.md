# Источники данных

Электронные конфигурации и распределение электронов по оболочкам:
[Bowserinator / Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON).

[Текст лицензии](https://creativecommons.org/licenses/by-sa/3.0/legalcode).
Копия описания лицензии включена в PERIODIC-TABLE-LICENSE.md.

Изменения: выбраны элементы 1–118, оставлены символы, номера, конфигурации
и числа электронов по оболочкам; в интерфейсе добавлены русские названия.
Производная выборка этих данных распространяется по той же лицензии.

Данные о ядрах и периодах полураспада: [IAEA LiveChart](https://nds.iaea.org/relnsd/vcharthtml/VChartHTML.html).
Ответ API ground_states получен 28.09.2026; использованы записи с Z=1–118.

Справочный источник электронных конфигураций:
[NIST](https://www.nist.gov/pml/atomic-reference-data-electronic-structure-calculations/atomic-reference-data-electronic-8).
